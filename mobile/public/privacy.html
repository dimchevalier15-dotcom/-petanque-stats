Politique de confidentialité — Pétanque Stats

Cette page décrit le traitement des données tel qu’il existe dans l’application. L’éditeur, l’email de contact doivent encore être complétés avant publication store.

Données traitées

  • Compte : adresse email, mot de passe (hashé côté serveur).
  • Profil joueur : prénom, nom, surnom.
  • Jeu : matchs terminés, entraînements, séances de tir de précision.
  • Sur l’appareil : jeton de session, langue, brouillons non encore envoyés.

L’application n’intègre pas de publicité ni d’outil d’analyse ou de crash reporting.

Finalité

Créer un compte, enregistrer les performances et afficher des statistiques de jeu.

Hébergement

Les données sont envoyées en HTTPS vers l’API https://api.petanque-analytics.com.

Partage

Les données ne sont pas vendues. Aucun SDK publicitaire n’est présent dans l’application.

Suppression

Vous pouvez supprimer votre compte dans l’application : Paramètres → Supprimer mon compte (également sur petanque-analytics.com/settings après connexion). L’email et le mot de passe sont effacés. Le profil joueur peut rester dans l’historique des matchs, sans lien avec un compte. La déconnexion efface uniquement le jeton local.
